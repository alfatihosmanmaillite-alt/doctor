# طبيب الهاتف (PhoneDoctor)

تطبيق Android بسيط (Java + XML) يفحص أسباب السخونة والبطء: حرارة البطارية، حالة الحرارة في النظام،
الذاكرة، التخزين، وضع توفير الطاقة، إعدادات الحركات، مدة التشغيل، وأكثر التطبيقات استخداماً.

## البناء عبر GitHub Actions
1. ارفع كل الملفات إلى مستودع GitHub (تأكد من وجود المجلد `.github/workflows/build.yml`).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (أو يعمل تلقائياً عند أي push).
3. بعد انتهاء البناء افتح التشغيلة ونزّل **PhoneDoctor-debug-apk** من قسم Artifacts.
4. فك الضغط وثبّت ملف `app-debug.apk` على الهاتف (اسمح بالتثبيت من مصدر غير معروف).
